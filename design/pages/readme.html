WorkTime

Free, open-source, self-hosted time tracker.

Single binary · local-first PWA · MCP server for AI agents

Go1.25 Svelte5 DBSQLite appPWA agentsMCP licenseMIT

Why WorkTime

Single binaryGo backend with the web UI embedded. Download, run, open localhost:8080. SQLite storage, no external services.
Local-first PWAWorks fully offline: timers keep running without a network and sync when it returns. Installable on your phone.
Multiple concurrent timersTrack parallel work honestly - running timers are data, not a UI hack.
Time off as dataVacation, sick leave and days off are first-class: shown in charts, counted in averages, never blocking tracking.
MCP serverAI agents start and stop timers, log time off and query reports over Model Context Protocol.
Reports that answer questionsInteractive daily chart, custom report builder, CSV export and a printable PDF report.
Tiny footprint~16MB RSS on the server, ~25KB gzip frontend, 11MB binary.
Multi-user, six languagesGoogle sign-in, per-user data isolation. UI in English, Russian, Spanish, German, French and Chinese.

Quick start

# binary
make build
WORKTIME_DEV_AUTH=1 ./bin/worktime
# docker
docker build -t worktime .
docker run -d -p 8080:8080 \
  -v worktime-data:/data worktime

MCP

Create an API token in Settings, connect any MCP client to /mcp with a Bearer token.

claude mcp add --transport http worktime https://your-host/mcp \
  --header "Authorization: Bearer <token>"
